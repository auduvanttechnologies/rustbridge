Write familiar. Compile native.

RustBridge translates Java into safe, idiomatic Rust, then compiles it, runs it, and repairs it until it prints exactly what your Java program prints. The Rust compiler and your program's own output check the work, not just a model.

$ curl -fsSL https://rustbridge.auduvanttechnologies.com/install.sh | sh

macOS and Linux. Needs Java 21+ and Rust. Or download the jar and run java -jar rustbridge.jar.

Java's references become Rust's borrows

Translating line by line produces code that doesn't compile. RustBridge reads the compiler's errors and fixes the root cause, here by borrowing instead of moving, without scattering .clone() everywhere.

Ownership.javainput
public class Ownership {
    public static void main(String[] args) {
        String name = "Genvium";
        String name2 = name;
        System.out.println(name2);
        System.out.println(name.length());
    }
}
src/main.rscompiled, output matches
fn main() {
    let name = String::from("Genvium");
    let name2 = &name;
    println!("{}", name2);
    println!("{}", name.len());
}
// first attempt moved `name` (error E0382);
// the repair borrows it instead of cloning

How it works

Compiling and running happen on your machine. RustBridge only sends the model what it needs to translate and repair.

Analyze

A real Java parser maps classes, interfaces and risky constructs before any model sees your code.

Translate

The model writes Rust using a small runtime that reproduces Java's number formatting, String.format, and HashMap order.

Compile & repair

cargo build runs locally. Compiler errors go back for targeted fixes until it builds.

Compare

Your Java program and the Rust both run. Any difference in output triggers another repair.

What you get

Every translation comes with a Cargo project and a report a human can review.

Output-verified

Byte-for-byte comparison against your Java program's real output, including doubles, formatting and map order.

No faked results

RustBridge flags translations that copy expected output into the code instead of computing it.

Idiom report

Counts clones, RefCells, unwraps and unsafe, plus decisions worth a second look.

Safe Rust only

Standard library plus the RustBridge runtime. No external crates, no unsafe.

Tested on hard Java

Built against a 70-program test suite: shared mutable state, inheritance, exceptions, generics, regex, overflow, UTF-16.

Your code stays yours

RustBridge needs your source to translate it. It doesn't need to keep it.

  • No code is stored. Source is sent for each model call and discarded. Only counts are kept: tokens, repairs, pass or fail.
  • Compiling and running stay local. Your Java and the generated Rust run on your machine, not ours.
  • Your API key isn't stored. With your own Anthropic key, it's used for that one request and never saved.
  • Anonymous reports can be turned off. Set RUSTBRIDGE_NO_REPORT=1. Reports never include code.
